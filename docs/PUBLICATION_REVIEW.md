# Проверка публичной версии

Дата проверки: **8 октября 2026 года**. Основа — default branch `main`
командного репозитория, коммит `4a79b39e3db758f95f093ebdbac4afb4a9f65116`.
Рабочие копии прежнего проекта и удалённые ветки не изменялись.

## Изменения для публикации

- Переписан единый README: задача хакатона, архитектура, запуск, собственные
  подключения сервисов, контракт, replay, тестирование, ограничения и публикация.
- Удалён личный абсолютный путь из README и привязка инструкций к имени старой
  локальной папки. Авторство команды и ссылка на исходный проект сохранены.
- Погодные URL вынесены в `OPEN_METEO_FORECAST_URL` и
  `OPEN_METEO_PREVIOUS_RUNS_URL`; в исходниках нет их действующих значений
  по умолчанию. `ML_SERVICE_URL` тоже пустой. Локальный запускатель формирует
  адрес своего ML-процесса самостоятельно.
- Шаблон `.env.example` оставляет URL и ключи пустыми. Пользователь задаёт свои
  значения. Публичные адреса провайдеров в README — справочные примеры.
- Добавлен отдельный `OPEN_METEO_API_KEY`. Ключ не включается в сохраняемые
  параметры запросов/manifest. URL с паролем, query или fragment отклоняется;
  HTTP-переадресации не выполняются в основном межсервисном пути и загрузчике.
- Удалён статический development signing secret. Локально он генерируется на
  время процесса; production требует собственные секреты.
- Удалена загрузка шрифта с Google. Фронтенд использует системные шрифты и не
  обращается к внешнему CDN для оформления.
- Расширен `.gitignore`, добавлены `SECURITY.md`, `NOTICE.md` и проверка
  `tools/check_publication.py`; права GitHub Actions ограничены чтением репозитория.
- Сохранены маршруты приложения, исходники обучения, реальные веса и эталонные
  запросы. Облачные сервисы не запускались, веса не переобучались.

## Автоматические проверки

Windows, Python 3.12.4, Django 5.2.17. Полный набор запускался с NumPy 2.5.3
и CPU PyTorch 2.6.0 для маленьких синтетических обучающих фикстур.

| `python -m pytest -q` | **117 passed, 28 subtests passed**, 2 предупреждения зависимостей |
| `manage.py check` | Ошибок нет |
| `manage.py makemigrations --check --dry-run` | Изменений моделей без миграций нет |
| `node --check static/app.js` | Синтаксис корректен |
| `git diff --cached --check` | Ошибок пробелов/конфликтов нет |
| `tools/check_publication.py` | Публикуемые файлы прошли проверку |
| SHA-256 включённой модели | Совпадает с исходным manifest |

SHA-256 неизменённого `models/production/model.json`:
`997066f7ddaeedbb6db840e2edfbaae947da487146b76949f076d1504b8ea55d`.

После копирования отдельно создано новое `.venv` из runtime-зависимостей.
`pip check` прошёл, миграции и создание двух турбин выполнены. В этой среде
успешно проверены HTTP-отдача Django-страницы и CSS, получение реальных ML
metadata через Django и `inference/smoke_test.py` для обеих турбин, включая
Bearer-авторизацию, повторяемость, отклонение неверного горизонта и источника.
Временные серверы остановлены. Новый локальный `db.sqlite3` содержит только
подготовленную структуру и две турбины и исключён из Git вместе с `.venv`.
Исходники при копировании побайтово проверены по SHA-256.

Тесты включают Django → реальный ML по localhost, обе турбины, эталонные
предсказания с допуском 2e-6, кэш, сохранение/экспорт, обработку 401, валидацию
погодных признаков и отсутствие демо-fallback. Новые проверки покрывают пустые
настройки, URL с учётными данными, переадресации, исключение ключа из manifest,
отсутствие ключей в `.env.example` и отказ production при пустых секретах.

В песочнице локальный ML-сервер не прошёл readiness; разрешённый повтор вне
песочницы успешно выполнил весь набор. Это ограничение окружения, не скрытый
пропуск тестов. Два оставшихся предупреждения — deprecation в Starlette/httpx
TestClient и pandas/NumPy timedelta; они не свидетельствуют о качестве модели.
